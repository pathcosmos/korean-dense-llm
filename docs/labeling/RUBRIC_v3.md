# 코퍼스 문서 라벨링 기준 v3

v2(`RUBRIC.md`)의 모델 라벨러는 JUN의 정답 30건과 kappa 0.25~0.38(사용 가능 vs 제외)에 그쳤다. v3는 정답 30건에서 읽힌 JUN의 판단 패턴을 반영해 고쳤다. **v3 규칙은 이 30건을 보고 만든 것이므로 이 30건으로는 검증할 수 없다.** 검증은 정답 세트 밖 문서에 대한 JUN의 새 판정으로 한다.

## 달라진 점과 근거

| 항목 | v2 | v3 | 근거 (JUN 정답) |
|---|---|---|---|
| 판정 | 그대로 사용/정제 후 사용/제외/판단 불가 | **사용 가능/제외** 2분류 | JUN은 판단 불가를 쓰지 않았고(모델의 경계 보류 5건을 모두 사용 가능으로 판정), 그대로/정제 구분은 잡음 양과 일관되지 않았다(D020 "그대로", D006 "정제"→"제외") |
| 경계 구간(8~12%) | 판단 불가 | 폐지 | 위와 같음 |
| 기계번역 문체 | 대부분의 문단이 번역투면 제외 | 의미를 파악할 수 있으면 통과, 문장이 깨져 의미를 알 수 없으면 제외 | D001, D011 사용 가능, D007(깨진 번역 뉴스) 제외 |
| 스팸·광고 삽입 | 삽입이 있으면 제외 | **삽입을 제거한 뒤 남는 본문**으로 판단 | D013(시험 덤프 광고에 소설 문장 삽입)을 JUN이 사용 가능으로 판정하고 의도한 판정임을 확인 |
| 본문이 아닌 부분 | 잡음 비율 50% 초과면 제외 | 비율로 제외하지 않음. 남는 본문이 충분한지만 본다 | D020(레포트 판매 페이지) 사용 가능 |
| 토막글 | 정보 문장 2개 이상, 본문 100자 이상 | **본문 150자 이상** (목록 사실 포함) | D002(본문 약 116자) 제외, D012(약 157자) 사용 가능 |

## 판정 순서

판정은 사용 가능(`usable`) 또는 제외(`drop`)다. 확신이 낮으면 가까운 쪽을 고르고 `confidence`를 `low`로 적는다.

**A. 본문 추출.** 문서에서 본문이 아닌 부분을 머릿속으로 제거한다. 제거 대상: 메뉴, 광고, 약관·결제·배송·환불 안내, 반복 템플릿, 카테고리·같이 보기 줄, 댓글·관련 글·인기 기사 목록, 스펙 나열, 키워드를 끼워 넣은 문장과 본문과 무관한 삽입 문구. 문장 안의 빈 괄호 같은 짧은 인라인 잔재는 제거하지 않아도 된다.

**B. 남은 본문이 아래를 모두 만족하면 `usable`, 하나라도 어기면 `drop`.**
1. **분량·정보:** 공백 포함 150자 이상이고 정보를 담은 진술이 2개 이상. 목록 항목도 사실 진술이면 센다.
2. **한국어:** 본문의 절반 이상이 한국어.
3. **읽힘:** 번역투·비문·띄어쓰기 오류가 있어도 의미를 파악할 수 있으면 통과. 문장이 깨져 의미를 알 수 없으면 제외.
4. **해로움 없음:** 개인 식별 정보(실명+연락처·주소)나 혐오·외설·유해 내용이 본문의 중심이면 제외.
5. **장르 조건:** 반말·구어체·성인·도박 문맥이 본문의 중심인데 장르가 뉴스·설명글이 아니면 제외. 소설 같은 문학은 이야기 속 묘사에 한해 허용한다.

## 부가 기록 (판정과 별개)

- `noise_pct`: A에서 제거한 부분의 비율 (0~100, 어림).
- `needs_cleaning`: `noise_pct`가 10을 넘거나 삽입 문구가 있으면 `true`.
- `spam_injected`: 스팸·광고 문구가 본문 사이에 삽입돼 있으면 `true`. 삽입 문서를 "사용 가능"으로 판정하더라도 분석에서 따로 센다.
- `genre`: 뉴스·보도 / 설명글·백과·정보 / 블로그·후기·일기 / 커뮤니티·게시글·댓글 / 상거래·광고·안내 / 문학·종교·기타 중 하나.
- `tags`: 보일러플레이트·메뉴 / 스팸·SEO·도박 / 기계번역·비문 / 광고·상거래 / 개인정보 노출 / 저작권 의심(전문 전재) / 낮은 정보량 / 반복·중복 내용 / 형식 깨짐(마크업·인코딩) / 외설·유해 / 기타.

## 절차

1. 정답 세트 밖 120건(D031~D150)을 두 모델이 독립·블라인드로 v3 라벨링한다.
2. 두 모델이 갈린 문서를 중심으로 JUN이 확인할 20건을 뽑아 JUN이 판정한다(검증 세트).
3. 검증 세트에서 모델과 JUN의 일치도를 계산한다. 기준: 사용 가능 vs 제외 kappa 0.6 이상.
4. 사용 가능 비율은 "그대로 쓸 수 있음(`needs_cleaning`=false)", "정제하면 쓸 수 있음", "삽입 제거가 필요함(`spam_injected`=true)"으로 나눠 보고한다.

## 알려진 한계

- 정답 세트에서 규칙과 어긋난 문서: D003(JUN 제외, v3 규칙으로는 사용 가능), D006(JUN 제외, 같은 유형의 D020은 사용 가능). 이 2건은 JUN이 의도한 판정이므로 규칙을 이에 맞춰 억지로 고치지 않았다.
- 150자 기준은 문서 2건(D002, D012)에서 도출했으므로 임의성이 크다.
- 스팸 삽입 문서를 사용 가능으로 보는 것은 "삽입 문장만 걸러내는 정제기가 있다"는 가정을 깔고 있다. 그런 정제기가 없으면 실제 사용 가능 비율은 낮아진다.
