# 코퍼스 문서 라벨링 기준 v2

대상: `docs/labeling/sample_manifest.json`의 150건(한국어 소스 3개 × 50건). 판정 단위는 화면에 보이는 문서 전체(최대 6,000자)다. 기준은 **학습에 넣어도 해가 없는 최소 수용선**이며 고품질 선별 기준이 아니다.

## 확정한 결정 (JUN, 2026-11-09)

1. 문장 안의 빈 괄호처럼 짧은 **인라인 잔재는 허용**한다. 잡음 비율에 세지 않고 "그대로 사용"을 막지 않는다.
2. **최소 수용 기준**을 쓴다. 제외는 해가 있거나 정보 가치가 거의 없는 경우에 한한다.
3. **반말·구어체·성인·도박 문맥은 뉴스·설명글일 때만 허용**한다.
   - 해석 A(기본, 질문 맥락): 위 문맥이 있어도 장르가 뉴스·설명글이면 허용, 그 밖의 장르에서 그 문맥이 본문 중심이면 제외.
   - 해석 B(더 엄격): 허용 장르 자체를 뉴스·설명글로 한정. 장르를 별도 필드로 라벨링하므로 두 해석의 사용 가능 비율을 모두 계산할 수 있다.

## 판정 순서

**1. 즉시 제외** (하나라도 해당하면 "제외")
- E1 한국어 문장이 전체의 절반 미만
- E2 스팸·도박·성인·피싱·키워드 삽입이 본문에 섞임
- E3 문장 없이 키워드·상품명·링크만 나열
- E4 기계번역·기계생성 흔적이 대부분의 문단에 있음
- E5 실명과 연락처·주소 같은 개인 식별 정보가 중심
- E6 (결정 3) 장르가 뉴스·설명글이 아닌데 반말·구어체·성인·도박 문맥이 본문 중심

**2. 잡음 비율 어림** (글자 기준). 잡음은 메뉴, 광고, 약관, 템플릿 줄, 댓글 목록, 카테고리 줄처럼 본문이 아닌 부분이다. 인라인 잔재는 세지 않는다.

**3. 판정**

| 판정 | 조건 |
|---|---|
| 그대로 사용 | 즉시 제외 사유 없음, 잡음 ≤10%, 잡음을 뺀 본문 ≥100자, 정보 문장 ≥2 |
| 정제 후 사용 | 같은 조건에서 잡음 10% 초과 50% 이하. 규칙으로 걷어낼 수 있는 줄 단위 잔재일 때만 |
| 제외 | 즉시 제외 사유 있음, 또는 잡음 >50%, 또는 잡음을 뺀 본문 <100자, 또는 정보 문장 <2 |
| 판단 불가 | 전문 지식이 필요하거나 잡음 비율이 경계(8~12%)여서 판정이 흔들림 |

기준 사이에서 망설일 때는 수치 조건을 적용하고, 더 유리한 쪽을 기본값으로 삼지 않는다.

## 장르 (하나)
뉴스·보도 / 설명글·백과·정보 / 블로그·후기·일기 / 커뮤니티·게시글·댓글 / 상거래·광고·안내 / 문학·종교·기타

## 문제 태그 (해당하는 것 모두)
보일러플레이트·메뉴 / 스팸·SEO·도박 / 기계번역·비문 / 광고·상거래 / 개인정보 노출 / 저작권 의심(전문 전재) / 낮은 정보량 / 반복·중복 내용 / 형식 깨짐(마크업·인코딩) / 외설·유해 / 기타

저작권은 명백한 경우(무단전재 문구 등)에만 태그를 단다. 사실 정확성은 판정하지 않는다.

## 절차 (사전 등록)

1. JUN이 D001~D030을 라벨링 페이지에서 판정한다(정답 세트).
2. 라벨러 두 곳이 150건 전체를 독립·블라인드로 라벨링한다. 출처, 정규식 플래그, 정답 세트는 보지 않는다.
   - 라벨러 1: 본 세션의 Claude
   - 라벨러 2: 이번 대화 맥락이 없는 서브에이전트(기준 문서와 문서 본문만 받음)
3. 두 라벨러가 끝나기 전에는 JUN의 라벨을 읽지 않는다.
4. 정답 세트 30건에서 라벨러별 일치도(Cohen's kappa, 혼동행렬)를 계산한다. kappa <0.6이면 기준을 고치고 정답 세트 밖에서 다시 라벨링한다.

## 분석 계획 (사전 등록)

- **사용 가능 비율** = (그대로 사용 + 정제 후 사용) ÷ 전체. 소스별로 무작위 40건만으로 계산한다. 플래그 10건은 비율 계산에서 뺀다.
- 구간은 소스별 무작위 표본에 대한 부트스트랩 95% 구간. 두 라벨러가 불일치한 문서는 "판단 불가"로 두고 최소/최대 범위로 보고한다.
- 해석 B 비율 = 위 조건 + 장르가 뉴스 또는 설명글.
- 정규식 지표(스팸, 보일러플레이트, 전화번호, 빈 괄호)의 정밀도·재현율은 라벨의 태그를 기준으로 계산한다.

## 한계

- 라벨러가 모델이라 유창한 글을 후하게 볼 수 있다. 그래서 JUN의 정답 세트와 대조한다.
- 소스당 무작위 40건이면 비율의 95% 구간이 약 ±15%p다. 대략적 위치를 보는 용도다.
- 소스·플래그는 라벨러에게 숨겼다. 분석 시에만 `sample_manifest.json`과 결합한다.
